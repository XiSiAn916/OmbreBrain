# Ombre Brain 遗忘曲线算法

## 为什么要遗忘？

> 如果什么都记得，那就什么都不记得了。

人脑擅长遗忘，因为遗忘帮助筛选出真正重要的东西。
Ombre Brain 的遗忘机制不是"丢数据"，而是**把不重要的事情沉到潜意识层**。

## Ebbinghaus 变体模型

经典 Ebbinghaus 遗忘曲线：遗忘速度先快后慢。

Ombre Brain 在此基础上增加了**强化机制**——每次被回忆，都会"补课"。

```
重要度衰减公式：

    S(t) = S₀ × e^(-λ × t) + ΔR

    其中:
    S(t)  = 当前重要度 (0.0 ~ 1.0)
    S₀    = 初始重要度 (由 ImportanceScorer 决定)
    λ     = 衰减系数 (默认 0.05，可调)
    t     = 距离上次触发天数
    ΔR    = 每次被回忆时的强化增量 (默认 +0.1)
```

## 参数配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 初始重要度 (新记忆) | 0.3 ~ 0.5 | 根据 ImportanceScorer 动态计算 |
| 衰减系数 λ | 0.05 | 越大忘得越快 |
| 强化增量 ΔR | +0.1 | 每次被回忆增加的重要度 |
| 活跃/沉睡分界线 | 0.3 | 低于此值沉入沉睡池 |
| 固化条件 - 最低重要度 | 0.85 | 必须持续高于此值 |
| 固化条件 - 最少触发次数 | 30 次 | 必须被回忆过这么多次 |
| 沉睡唤醒增幅 | +0.25 | 被关联触发唤醒时一次性增加 |
| 每日检查时间 | App 首次启动 + 每6小时 | 遗忘曲线 tick |

## 特殊规则

### 1. 情感加成

如果一条记忆伴随强烈情感（你的情绪波动大），衰减速度减半：
```
λ_emotional = λ / 2
```

### 2. 用户主动引用

如果你在对话中主动说"你还记得上次……吗？"
→ 该记忆重要度直接 +0.2（一次大幅强化）
→ 相当于人脑中的"刻意复习"

### 3. 睡前加固

研究表明睡眠有助于记忆巩固。如果一条记忆在**睡前 1 小时内**被触发过：
→ 该记忆的衰减延期 2 天（即 2 天内不会衰减）

### 4. 关联网络强化

当记忆 A 被触发时，和 A 关联度高的记忆 B、C 也会获得少量强化：
```
ΔR_关联 = ΔR × 关联度(0~1) × 0.5
```


## 代码接口设计（示意）

```kotlin
// 遗忘曲线引擎
class ForgettingCurve(
    private val decayRate: Double = 0.05,
    private val reinforceAmount: Double = 0.1,
    private val dormantThreshold: Double = 0.3,
    private val habitThreshold: Double = 0.85,
    private val habitMinCount: Int = 30
) {
    // 每日检查：更新所有记忆的重要度
    fun tick(memories: List<Memory>): List<MemoryUpdate>
    
    // 强化记忆（被回忆时调用）
    fun reinforce(memory: Memory, context: ContextInfo): Double
    
    // 检查是否应转为 Habit
    fun shouldHabitize(memory: Memory): Boolean
    
    // 唤醒沉睡记忆（关联触发时）
    fun awaken(memory: Memory): Double
}
```
