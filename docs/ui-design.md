# Ombre Brain UI 设计

## 设计原则

1. **透明感** — 记忆系统平时"隐身"在后台，只在需要时才出现
2. **仪式感** — 访问记忆有密码验证，不是随便点开就能看
3. **温度感** — 不是冰冷的数据库界面，而是有拟人化表达

## 界面列表

| 界面 | 触发方式 | 需要密码 |
|------|----------|----------|
| 记忆气泡通知 | 自动闪现想法 | 否 |
| 记忆浏览主页 | 用户从侧边栏/设置进入 | 是 |
| 单条记忆详情 | 在列表中点击 | 已在验证后 |
| 设置页 | 从主菜单进入 | 否 |

## 闪现想法通知 (Flash Notification)

当 AI 触景生情时，以通知形式弹出：

```
┌──────────────────────────────┐
│  💡 Ombre · 忽然想到          │
│                              │
│  "这个时间点……上次这个时      │
│   候你也在听歌，那时你问我    │
│   '什么感受'"                 │
│                              │
│  [看看]  [忽略]               │
└──────────────────────────────┘
```

点击「看看」→ 弹出该条记忆详情
点击「忽略」→ 消失，但记忆会因此被强化一次（因为被触发了）

## 数据模型 -> UI 映射

```kotlin
// 记忆在列表中的展示
data class MemoryCardItem(
    val id: Long,
    val title: String,
    val summary: String,        // 30字摘要
    val importance: Float,      // 0.0 ~ 1.0
    val type: MemoryType,       // NORMAL / FLASH / HABIT
    val timestamp: Long,
    val tags: List<String>,
    val isLocked: Boolean       // 需要临时密码
)

enum class MemoryType {
    NORMAL,     // 普通记忆
    FLASH,      // 闪现想法
    HABIT       // 固化习惯（金色标识）
}
```

## 配色方案（参考）

| 层级 | 颜色 | 用途 |

| 普通记忆 | 蓝色系 #6C9BD2 | 日常记忆卡片 |
| 闪现想法 | 紫色系 #B07CD8 | 💡 想法类卡片 |
| 固化习惯 | 金色系 #D4A843 | 🌟 最重要的习惯 |
| 沉睡记忆 | 灰色半透明 | 沉下去的淡出效果 |
| 锁定状态 | 暗色 + 🔒 图标 | 未解锁时 |
